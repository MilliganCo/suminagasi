# Suminagashi Simulation

> Public source preview: see [PUBLICATION.md](PUBLICATION.md) for actual checks, known failures and runtime limits.

Реализация симуляции распространения чернил на воде (Suminagashi) в реальном времени с использованием GPU compute шейдеров.

## Описание

Это приложение симулирует физику распространения чернил на поверхности воды, используя модель Marangoni flow (поток, вызванный градиентами поверхностного натяжения). Симуляция выполняется полностью на GPU с использованием compute шейдеров для максимальной производительности.

## Физическая модель

### Уравнения

Модель основана на следующих полях:
- **Γ(x,y,t)** - поле поверхностно-активного вещества (surfactant)
- **C(x,y,t)** - поле пигмента (RGB цвет)
- **u(x,y,t)** - скорость поверхности

**Поверхностное натяжение:**
```
σ(Γ) = σ₀ - E·Γ
```

**Marangoni скорость:**
```
u_mar = -αE ∇Γ
```

**Транспорт (advection-diffusion):**
```
∂Γ/∂t + u·∇Γ = D_Γ ∇²Γ
∂C/∂t + u·∇C = D_C ∇²C
```

### Численные методы

- **Advection**: Semi-Lagrangian метод (стабильный для реального времени)
- **Diffusion**: Неявный метод Якоби (Jacobi iteration)
- **Градиенты**: Центральные разности
- **Лапласиан**: 5-точечный шаблон

## Сборка и запуск

### Требования

- Rust (edition 2021 или новее)
- Windows (тестировано на Windows 10/11)
- GPU с поддержкой compute shaders (DirectX 11 или Vulkan)

### Установка Rust

Если Rust не установлен, следуйте инструкциям в файле [INSTALL.md](INSTALL.md).

Кратко:
1. Скачайте и установите Rust с https://rustup.rs/
2. Перезапустите терминал/PowerShell
3. Проверьте установку: `cargo --version`

### Сборка

```powershell
cargo build --release
```

### Запуск

```powershell
cargo run --release
```

## Управление

### Мышь

- **Левая кнопка мыши**: Добавить чернила (surfactant + пигмент)
- **Правая кнопка мыши**: Добавить дисперсант (отрицательный surfactant)
- **Колесо мыши**: Изменить радиус капли

### Клавиатура

- **Пробел**: Пауза/возобновление симуляции
- **R**: Сброс всех полей
- **1**: Граничные условия CLAMP (зажим)
- **2**: Граничные условия WRAP (периодические)
- **3**: Включить/выключить слабые волны
- **+/-**: Увеличить/уменьшить силу Marangoni (α)
- **[/]**: Уменьшить/увеличить количество итераций диффузии
- **C**: Переключить цвет чернил

## Параметры симуляции

Параметры по умолчанию (настраиваются в `src/sim/params.rs`):

- **N**: 1024 (размер сетки)
- **dt**: 1/60 секунды
- **αE**: 0.25 (комбинированный масштаб Marangoni)
- **u_max**: 1.0 (максимальная скорость)
- **D_surf**: 0.0005 (диффузия surfactant)
- **D_pig**: 0.0001 (диффузия пигмента)
- **Jacobi iterations**: 15 для surfactant, 10 для пигмента
- **Substeps**: 2 (подшаги на кадр)

### Волны (опционально)

- **H**: 0.02 (глубина)
- **g**: 9.8 (гравитация)
- **r**: 1.0 (затухание)
- **β**: 0.05 (сила связи)

## Технические детали

### GPU Pipeline

Каждый кадр выполняет следующие этапы (для каждого substep):

1. **Inject**: Добавление чернил/дисперсанта в поля
2. **Velocity**: Вычисление скорости из градиента surfactant
3. **Waves** (опционально): Обновление слабых волн
4. **Advect Surfactant**: Перенос surfactant полем скорости
5. **Diffuse Surfactant**: Диффузия (Jacobi итерации)
6. **Advect Pigment**: Перенос пигмента полем скорости
7. **Diffuse Pigment**: Диффузия пигмента (Jacobi итерации)
8. **Render**: Отображение поля пигмента на экран

### Форматы текстур

Все симуляционные текстуры используют формат `Rgba16Float`:
- Surfactant: значение в `.x` канале
- Pigment: RGB в `.xyz` каналах
- Velocity: вектор в `.xy` каналах

### Граничные условия

- **CLAMP**: Значения за пределами [0,1] зажимаются к краю
- **WRAP**: Периодические граничные условия (текстура повторяется)

## Производительность

Приложение оптимизировано для работы на средних GPU:
- Целевая производительность: 60 FPS при N=1024
- Fallback: N=512 для слабых GPU
- Все вычисления выполняются на GPU, без CPU readback (кроме опционального скриншота)
